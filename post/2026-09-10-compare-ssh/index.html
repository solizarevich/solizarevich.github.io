Для подключения к Linux-серверам вполне достаточно обычного ssh в терминале. Но когда серверов становится много, появляются jump-хосты, туннели, SFTP, сохранённые подключения и несколько одновременных сессий — графический SSH-клиент может заметно упростить работу.

Для себя я выделил три бесплатных проекта с открытым исходным кодом:

  • Tabby
  • Skerry
  • Electerm

На первый взгляд они решают одну задачу, но на практике подход у них заметно отличается.

Данные в статье актуальны на сентябрь 2026 года.

Коротко: чем отличаются

Tabby — в первую очередь современный терминал, в который хорошо интегрирован SSH.

Skerry — SSH-клиент и набор инструментов для работы с удалённой инфраструктурой с акцентом на local-first, собственное хранилище и self-hosted-синхронизацию.

Electerm — универсальный клиент, который объединяет терминал, файловый менеджер, SSH и сразу несколько протоколов удалённого доступа.

Набор возможностей Tabby включает SSH2, Telnet, Serial, X11 и port forwarding, автоматическую работу с jump-хостами, Agent Forwarding и менеджер подключений. Проект также поддерживает плагины, включая расширения для SFTP, Docker и синхронизации конфигурации.

Skerry поддерживает SSH, ProxyJump, Mosh, Telnet, Serial, docker exec, kubectl exec, локальный shell, SFTP, RDP и VNC. Есть локальные, обратные и SOCKS-туннели, сниппеты, сценарии выполнения команд и собственное зашифрованное хранилище.

Electerm объединяет SSH, SFTP, FTP, Telnet, Serial, RDP, VNC и Spice. Также поддерживаются SSH-туннели, Agent Forwarding, X11, прокси, редактирование файлов через SFTP, разделённые терминалы и синхронизация конфигурации.

Tabby — когда нужен прежде всего хороший терминал

Tabby существует уже давно и является самым известным проектом из этой тройки. На GitHub у него более 74 тысяч звёзд. Проект распространяется по лицензии MIT.

По своей философии Tabby ближе не к классическому менеджеру серверов, а к современному терминалу.

Он может заменить стандартный Terminal в macOS, Windows Terminal или старые решения вроде PuTTY, при этом оставить SSH-подключения прямо внутри привычного терминального интерфейса.

Есть:

  • вкладки;
  • разделение окна на несколько терминалов;
  • сохранение сессий;
  • менеджер SSH-подключений;
  • jump-хосты;
  • проброс портов;
  • X11 Forwarding;
  • Agent Forwarding;
  • SSH, Telnet и Serial;
  • зашифрованное хранилище SSH-данных;
  • поддержка плагинов;
  • темы и большое количество настроек.

На Windows отдельно удобно, что Tabby умеет работать с PowerShell, WSL, Git Bash, Cygwin, MSYS2, CMD и другими локальными оболочками.

То есть приложение можно использовать вообще без SSH — просто как основной терминал.

Кому подойдёт Tabby

Если большую часть времени вы проводите именно в терминале и хотите получить удобный интерфейс поверх SSH — Tabby выглядит наиболее естественным вариантом.

Особенно если RDP, VNC и встроенный файловый менеджер вам не нужны.

Что учитывать

Сам разработчик прямо отмечает, что Tabby не относится к лёгким терминалам. Если потребление памяти критично, существуют более минималистичные решения.

Desktop-версии есть для Windows, macOS и Linux. Полноценного мобильного клиента в основной версии нет.

Skerry — интересный новый подход

Skerry из всей тройки самый молодой проект.

Вместо простого «терминала с SSH» разработчик пытается сделать единое приложение для администрирования удалённых систем.

В нём есть:

  • SSH;
  • Mosh;
  • Telnet;
  • Serial;
  • SFTP;
  • RDP;
  • VNC;
  • ProxyJump;
  • Local, Remote и SOCKS-туннели;
  • docker exec;
  • kubectl exec;
  • сниппеты;
  • сценарии выполнения команд;
  • мониторинг CPU, памяти, дисков и сети;
  • запись терминальных сессий;
  • синхронный ввод команд сразу в несколько терминалов;
  • Android-клиент.

Интересно реализован SFTP: вместо отдельного простого окна используется двухпанельный файловый менеджер — локальная машина с одной стороны и удалённый сервер с другой.

Есть и Mosh, которого нет в двух других рассматриваемых клиентах. Он может быть полезен при работе через нестабильное соединение.

Local-first и синхронизация Skerry

Отдельная идея Skerry — минимальная зависимость от сторонней облачной инфраструктуры.

Приложение полностью работает без аккаунта. По заявлению проекта, данные о хостах, пароли, SSH-ключи, история терминала и другие чувствительные данные по умолчанию не отправляются во внешнее облако.

Для хранения секретов используется локальное зашифрованное хранилище.

Если нужна синхронизация между компьютером и Android-смартфоном, можно поднять собственный сервер Skerry. Он разворачивается контейнером и может использовать SQLite или PostgreSQL.

Такой подход особенно интересен тем, кто не хочет хранить инфраструктурные подключения в облаке производителя SSH-клиента.

ИИ в Skerry

Есть и встроенный ассистент.

Можно использовать локальную модель либо собственный API-ключ. Для отдельных серверов задаётся политика, определяющая, разрешено ли вообще отправлять данные облачной модели. Предложенные ИИ команды автоматически не выполняются — перед выполнением требуется подтверждение.

Для production-хостов предусмотрена дополнительная проверка потенциально опасных команд.

Но со Skerry есть важный нюанс

Проект пока находится на ранней стадии.

На момент написания статьи актуальный релиз — v0.4.3 от 30 августа 2026 года. Сам разработчик обозначает Skerry как pre-1.0.

Более того, в документации по безопасности отдельно указано, что используемая проектом криптографическая архитектура пока не проходила независимый внешний аудит. Используются известные библиотеки и алгоритмы, но конкретная реализация Skerry проверялась только самим проектом.

Сборки Windows и macOS также пока не подписаны, поэтому при первом запуске Windows SmartScreen или macOS Gatekeeper могут показать предупреждение.

Поэтому Skerry сейчас я бы рассматривал прежде всего как очень интересный развивающийся проект, за которым стоит следить и который можно протестировать, а не как безоговорочно более зрелую замену Tabby.

Electerm — настоящий комбайн

Если смотреть исключительно на количество встроенных возможностей, Electerm выглядит наиболее универсально.

Он совмещает:

  • терминал;
  • SSH;
  • SFTP;
  • FTP;
  • Telnet;
  • Serial;
  • RDP;
  • VNC;
  • Spice;
  • файловый менеджер.

То есть из одного приложения можно подключиться по SSH к Linux-серверу, передать файлы через SFTP, а затем открыть удалённый Windows-сервер по RDP.

Есть SSH-туннели, X11 Forwarding, Agent Forwarding, jump-соединения и прокси.

Удалённый файл можно открыть двойным кликом прямо из встроенного SFTP-менеджера, отредактировать и сохранить обратно на сервер.

Синхронизация Electerm

Для закладок, тем и быстрых команд поддерживается несколько вариантов синхронизации:

  • GitHub/Gitee Gist;
  • WebDAV;
  • пользовательский сервер;
  • Electerm Cloud.

То есть здесь пользователь сам может выбрать между облачным вариантом и собственной инфраструктурой.

ИИ и MCP

В Electerm уже встроена довольно серьёзная ИИ-интеграция.

Можно подключать API, совместимые с OpenAI, и использовать модель для:

  • генерации команд;
  • объяснения команд;
  • написания скриптов;
  • создания подключений;
  • автоматизации отдельных действий.

Есть также поддержка MCP для взаимодействия с внешними ИИ-инструментами.

Платформы Electerm

Это ещё одно заметное преимущество.

Electerm работает на:

Windows, macOS, Linux, Android, iOS и HarmonyOS.

Причём поддерживаются даже сравнительно старые системы, включая Windows 7 и Linux-дистрибутивы с glibc 2.17+.

Проект распространяется по лицензии MIT, на GitHub у него более 15 тысяч звёзд. Актуальная на момент написания статьи версия 5.3.26 вышла 3 сентября 2026 года.

Что в итоге выбрать

Здесь нет одного победителя.

Я бы выбрал Tabby, если нужен в первую очередь удобный современный терминал с SSH, вкладками, панелями и большим количеством настроек.

Skerry стоит попробовать, если интересны Mosh, Android, RDP/VNC, Docker/Kubernetes, собственная синхронизация и подход local-first. Но нужно учитывать молодость проекта и статус pre-1.0.

Electerm стоит смотреть, если хочется получить максимально универсальное приложение: SSH + SFTP + FTP + RDP + VNC + Spice и мобильные клиенты в одном месте.

Поэтому выбор можно свести к простой формуле:

Tabby — терминал.
Skerry — управление удалённой инфраструктурой с упором на приватность.
Electerm — универсальный комбайн удалённого доступа.

Все три проекта бесплатные, поэтому лучший способ выбрать — поставить два-три клиента и проверить их уже на своих реальных сценариях.
